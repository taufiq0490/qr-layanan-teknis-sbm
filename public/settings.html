💡 Panduan Menghubungkan WhatsApp Gateway Gratis (Fonnte):
  1. Buka fonnte.com dan buat akun gratis.
  2. Hubungkan nomor WhatsApp staf/bot dengan scan QR di dashboard Fonnte.
  3. Salin API Token yang diberikan Fonnte ke form di bawah ini.
  4. Masukkan nomor WhatsApp staf penerima notifikasi, lalu klik Simpan & Uji Coba Kirim.
*Catatan: Selama token belum diisi, sistem berjalan dalam Mode Simulasi (semua pesan tercatat di dashboard & log server tanpa error).
