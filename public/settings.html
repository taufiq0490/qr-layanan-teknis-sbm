Penyimpanan Cloud KV (Upstash Redis / Vercel KV)

ℹ️ Mengapa Menggunakan Cloud KV di Vercel?
Vercel Serverless memiliki sifat multi-instance (wadah terpisah). Menggunakan database Redis gratis dari Upstash.com (atau Vercel KV) memastikan data panggilan 100% konsisten & tidak pernah hilang-timbul di semua perangkat.
Dapatkan REST URL gratis dari dashboard Upstash Redis ➔ tab REST API.
